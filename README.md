# Radar Zone Presence

Home Assistant custom integration that turns the target coordinates of
LD2450-style mmWave radar sensors (Everything Presence Lite, Screek Human
Sensor 2A, …) into named polygon presence zones — drawn in a dedicated editor,
checked against a history point cloud, and debuggable with a replay scrubber.

**Status:** design phase, nothing to install yet. See [DESIGN.md](DESIGN.md)
for the plan and [DEVELOPMENT.md](DEVELOPMENT.md) for the dev setup.
